# Viriditas Hora App

A Vite React prototype for Viriditas Hora: The Living Power of the Hour.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## What is included

- Free / Seeker / Initiate tier preview
- Planetary hour flow
- Moon phase guidance
- Energy check-in
- Journal prompts
- Alignment categories
- Tier locking UI
- Sacred names and angelic correspondences in Initiate preview

This is a front-end prototype. Payments, login, saved journals, birth chart integration, and notifications need backend/native app setup next.
