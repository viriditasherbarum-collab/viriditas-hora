# Viriditas Hora V2

A more mystical, mobile-first version of Viriditas Hora.

## What changed
- First-time location setup
- Browser GPS option
- Cleaner mobile-app layout
- Less cluttered Home screen
- Bottom navigation
- Planetary hour calculation based on sunrise/sunset
- Free / Seeker / Initiate tier preview inside Profile

## Vercel settings
Framework: Vite
Build command: npm run build
Output directory: dist
Install command: npm install
